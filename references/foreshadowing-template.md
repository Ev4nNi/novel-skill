## Status Legend
- planned: setup written, payoff not yet delivered
- planted: setup chapter drafted
- in-flight: payoff chapter drafted, status uncertain
- paid: payoff delivered
- dropped: user approved abandoning this setup (log decision)
- escalated: setup upgraded into a major plot point (log decision)
