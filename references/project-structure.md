# Project Structure

Before creating any project files, ask the user to choose one mode:

- `Obsidian`
- `folder + Markdown`

Use this layout for a new novel project:

```text
novel-project/
  00-project/
    正文写作指南.md
  01-worldbuilding/
  02-characters/
  03-plot/
  04-volumes/
  05-chapters/
  06-timeline/
  07-lore-index/
  08-review/
```

Use the same layout for Obsidian and plain Markdown.

## Stage Rule

Do not build every folder in one pass and then start writing the whole story.

Move stage by stage:

1. confirm project positioning
2. confirm worldbuilding framework
3. confirm character framework
4. confirm master outline framework
5. confirm volume breakdown framework
6. confirm chapter card framework
7. draft only the current step

Advance only after the user confirms the current stage.

## Folder Responsibilities

- `00-project`: premise, goals, style guide, progress
- `00-project/正文写作指南.md`: stable prose drafting rules, tone guardrails, continuity reminders, and chapter-writing checks
- `01-worldbuilding`: rules, factions, geography, power system
- `02-characters`: character cards and relationship updates
- `03-plot`: master outline, arcs, conflict design, foreshadowing
- `04-volumes`: volume or arc plans
- `05-chapters`: chapter cards and chapter drafts
- `06-timeline`: chronology and event log
- `07-lore-index`: locations, terms, items
- `08-review`: consistency checks and revision notes

## Update Rules

Update the matching files immediately after any new prose changes project facts.

In Obsidian mode, prefer `[[double links]]` for people, places, organizations, items, and events.

When a volume is completed, immediately repair these files before starting the next volume:

- `01-worldbuilding/` core setting files
- `03-plot/master-outline.md`
- `03-plot/foreshadowing.md`
- `03-plot/reveals.md`
- `06-timeline/` files
- `00-project/正文写作指南.md` if the writing rhythm or guardrails need adjustment
