# Phase 5 — Volumes

**Goal:** Split the story into volumes, each volume a self-contained escalation step.

**Input:** `03-plot/master-outline.md`, `foreshadowing.md`, `reveals.md`, all character/world files, prior volume's Volume Repair
**Output:** `07-pre/volumes/Volume-XX-pre-review.md`, `04-volumes/Volume-XX.md`, `10-review/volume-reports/Volume-XX-repair.md`

**Prerequisite:** Phase 4 confirmed.

## Pre-Volume Review (mandatory for every volume, including volume 01)

1. Read every relevant file from earlier phases.
2. Fill `references/pre-volume-review-template.md` and save it as `07-pre/volumes/Volume-XX-pre-review.md`.
3. List conflicts and present 2-3 repair options for each.
4. Get user sign-off before drafting the volume card.

## Volume card

1. Use `references/volume-template.md` and save to `04-volumes/Volume-XX.md`.
2. Reference the Pre-Volume Review file from the volume card.
3. Confirm with the user.

## Volume Repair (mandatory after the volume is fully drafted)

1. Fill `references/volume-repair-template.md` and save to `10-review/volume-reports/Volume-XX-repair.md`.
2. Update master-outline, foreshadowing, reveals, timeline, lore-index.
3. Log the repair in the decision log.

**Note:** `07-pre/volumes/` contains the pre-review (intermediate product). `04-volumes/` contains the volume card (stable product). They are separate to avoid loading all pre-reviews when reading volume cards.

**Read before starting:** `phases/00-overview.md`
